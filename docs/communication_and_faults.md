# 视觉—电控通信约定与异常处理

## 当前建议协议

- 物理链路：优先 USB CDC；备选 UART + CH340。
- 参数：115200 波特率、8 数据位、无校验、1 停止位（115200 8N1）。
- 发送频率：20 Hz。
- 消息：ASCII 文本，每条以 `\n` 结束。

```text
AIM,1,-45,18
AIM,0,0,0
```

字段依次为：`AIM,valid,error_x,error_y`。`valid=0` 时 STM32 必须停止云台更新，激光关闭。

坐标约定：

- `error_x > 0`：靶心在画面右侧。
- `error_x < 0`：靶心在画面左侧。
- `error_y > 0`：靶心在画面下方。
- `error_y < 0`：靶心在画面上方。
- 单位为像素。

## 可以由视觉组和电控组自行约定的内容

1. 使用 USB CDC 还是普通 UART。
2. 波特率、发送频率、文本协议还是二进制协议。
3. 消息字段、帧头帧尾、是否增加序号和校验和。
4. X/Y 正方向和舵机正方向的映射。
5. `LOCKED` 像素阈值、连续确认帧数、瞄准超时时间。
6. PID 放在电脑还是 STM32；建议 STM32 执行 PID 和舵机限幅。
7. 到达 A/C/D/B 后由谁触发瞄准、何时打开激光、驻留多久。

比赛规则和物理条件不能自行改变：靶纸尺寸、场地尺寸、四个打靶点、激光规格及安全要求等。

## 建议的停车打靶状态机

```text
DRIVING
  -> 到达 A/C/D/B
SETTLING（停车等待 300~600 ms）
  -> 视觉连续确认
AIMING
  -> 连续 5 帧误差在阈值内
LOCKED
  -> 激光驻留
SHOT_DONE
  -> 继续循迹
```

## 异常处理

| 异常 | 视觉端行为 | STM32 必须执行 |
|---|---|---|
| 靶框单帧丢失 | 显示 HOLD，但发送 `AIM,0,0,0` | 云台停止，激光关闭 |
| 靶框连续丢失 | SEARCHING，清除旧中心 | 云台停止，激光关闭 |
| 中心突然跳变 | 重新累计 3 个确认帧 | 忽略无效帧 |
| 摄像头读取失败 | 发送一次无效消息并退出 | 超时保护 |
| 串口断开/电脑死机 | 无法继续发送 | 超过 200 ms 未收到有效帧即停止云台并关激光 |
| STM32 重启 | 视觉保持未解锁 | 必须重新进入指定点瞄准状态 |
| 舵机方向相反 | 激光关闭，单轴低速测试 | 修改方向符号，不改视觉坐标定义 |
| 舵机到机械极限 | 不继续累积控制量 | PWM/角度限幅，必要时上报故障 |
| 车身剧烈晃动 | 不发送有效误差 | 只在停车稳定后允许瞄准 |

激光必须默认关闭。只有车辆已在指定点停车、视觉稳定锁定、人员确认安全时，STM32 才允许短时打开激光。
